# shared/ —— 跨模块小工具

> 最后更新：2026-09-30

## 这个目录是干什么的

放**到处都可能用到、又不属于任何单一业务**的小工具。
目前只有两个：JSON 容错解析、参数校验。

## 文件清单

| 文件 | 功能 | 影响 / 依赖 |
|--|--|--|
| `json_utils.py` | JSON 宽容解析（AI 返回的 JSON 常有尾逗号/单引号/```围栏，直接 `json.loads` 会炸） | 被 prompt 解析类代码用 |
| `validation.py` | 参数校验小工具（类型/范围/必填） | 被 `mcp_server` 入参检查用 |
| `__init__.py` | 包标记 | — |

## 关键约定与坑

- **这里不放业务逻辑**。一旦某个函数开始依赖 `services/` 里的东西，
  它就说明该搬到 `services/` 了，别放这里养大。
- 无副作用、无 I/O（除解析），可以放心被任何层 import。

## 相关目录

- 业务逻辑：`../services/`
- MCP 门面：`../mcp_server/`
