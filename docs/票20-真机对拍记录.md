# 票 #20 真机对拍记录（派生侧接入）

> 建档：2026-11-23，出自票 #20「派生侧接入：规则产出 padstack」的验收⑤：
> 至少 1 件真机产物（建图 → 回读）与改造前逐字段对拍一致。
> 本文件只记**做过什么、看到什么**；结论与数字都能按上面的命令复跑。

## 目的

规则驱动派生（票 #20）改掉了「建封装时谁决定 padstack 形状」。离线对拍
（`eval/baselines/padstack_derive.json` + R5）只能证明**函数输出**没变；验收要的是
**宿主里真建出来的那颗封装**没变。所以同一份 spec 用改造前 / 改造后两套代码各建一次，
再回读对比。

## 环境与方法

| 项 | 内容 |
|--|--|
| 样本 | `knowledge/specs/nb_cstj421_aj35_6p.json`（TH 长圆 6 脚：覆盖派生改名、TH 六层、pin 补 rotation=90 三条路径） |
| 改造前 | `git worktree add .agent-cache/ticket20/oldtree 1e917f6`（#18 的提交；`import` 路径实测指向 oldtree） |
| 改造后 | 工作区（#20 改动） |
| 宿主 | Allegro SPB 17.2 + SkillBridge（`127.0.0.1:7777`） |
| 建图 | 走 MCP（`python -m mcp_server.server` + `mcp` SDK stdio）：`build_footprint_from_params`（`fresh_symbol=False`, `on_exists="skip"`, `auto_extent=True`）→ `export_psm` → `read_full_footprint` |
| 模板 | 双方都从同一份 17.2 空白模板 `.dra` 起（官方 `sym_template.dra` 是 16.0，会被「release 16.0 will be updated」升级框拒掉，故用清空后的 17.2 副本：pins=0 / texts=0 / lines=0，仅余 2 个外来 padstack，与本件 padstack 不同名） |
| 开图方式 | 必须走 `services/skillbridge_writer.AllegroSession`（带 `_handshake()`）。裸 `Workspace.open` 调 `axlOpenDesign` 会往 FIFO 里多塞帧，之后所有连接读到陈旧回复（表现为 `axlDBGetDesign()` 返回 None、MCP 报 `CHANNEL_NOT_READY`） |
| 产物落点 | `.agent-cache/ticket20/real/old3/` 与 `.agent-cache/ticket20/real/new3/`（缓存区，不进版本控制） |

## 结果

| 对比对象 | 改造前 | 改造后 | 结论 |
|--|--|--|--|
| `.dra` 字节数 | 77748 | 77748 | 同 |
| `.psm` 字节数 | 10616 | 10616 | 同 |
| padstack 名 | POB1D6X0D6HOB2D2X1D2 / POB1D4X0D6HOB2X1D2 / POB1X0D7HOB1D6X1D3 | 同左 | 同 |
| `.pad` 字节数 | 3004 / 3000 / 3000 | 同左 | 同 |
| `read_full_footprint` 回读 JSON | — | — | **0 处差异**（pins=6 / pads / bbox / layers / texts / ref_des / symbol_name 全一致；忽略 source_file、dra_path、pad_file、psm_path、created_at、timestamp 六个指路字段） |
| build 报告 | — | — | 除路径字符串与一条「工作目录不一致已自动切」的警告外 **0 差异** |

`.pad` 逐字节差 164 字节：全部落在文件头（偏移 36–38）与每条 8 字节记录的前 3 字节
（60/68/76/84…），属对象标识 / 时间戳标记；层尺寸与钻孔的双精度字节、ASCII 内容
（BEGIN LAYER / COPPER / FR-4 / PRIMARY / padstack 名）完全相同 —— 所以 `.pad` **不能
按哈希判等**，判据是回读字段与派生定义。

## 结论与局限

- 结论：同一份 spec 在改造前 / 改造后的代码上建出的封装，回读字段逐项一致（0 差异）。
- 局限：只覆盖 1 件样本、TH 长圆一种形态；SMD 的派生与 TH 圆孔 / 其它孔形的 SKIP
  路径由离线 R5（含合成读数）覆盖，真机链路未逐一重建。
- Allegro 收尾：`Tools/stop_allegro.py` 关进程 + 收回后台 shell + `Tools/collect_logs.py`
  归集日志（本次归集到 `Tools/log/allegro_20261123-114216.jrl`）。
