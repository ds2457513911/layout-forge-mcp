

> 用途：给它一份规格书 PDF，自动算出尺寸并在 Allegro 里把封装画出来，产出可直接使用的封装文件。

***

## 一、工具背景

### 1.1 人工封装

工程师在 Allegro 里手工建封装：查规格书找尺寸 → 算焊盘大小 → 算每个脚的坐标 → 一个焊盘一个焊盘建、摆、改 padstack → 画丝印、画本体、画占位框 → 编译 → 再自查一遍。

| 问题  | 表现                        |
| --- | ------------------------- |
| 慢   | 一个器件几十步手工操作，引脚越多越久        |
| 易错  | 坐标算错、padstack 尺寸填错，肉眼很难发现 |
| 难复用 | 换个人做，尺寸口径、命名习惯都不一样        |

### 1.2 自动化封装

把规格书 PDF 放好，**在对话框里输入**：

```
帮我根据这份规格书建立封装：<规格书路径或文件夹>
```

剩下的事 AI 自己做：定位尺寸页 → 读参数 → 算几何 → 驱动 Allegro 画出封装 → 编译出成品 → 归档。**日常使用不需要敲任何命令。**

> **输入**：一份规格书 PDF；
> **输出**：封装三件套（`.dra` 图纸 / `.psm` 成品 / `.pad` 焊盘），可直接进检查工具验收。

### 1.3 和"封装检查"接力

公司里还有一个"封装自动检查"工具（比对规格书与封装，出判定报告）。两个工具是一前一后的关系：

```
规格书 ──▶【自动生成】──▶ 封装文件 ──▶【自动检查】──▶ 判定报告
                              ▲                            │
                              └──────── 不合格？改了再查 ─────┘
```

生成工具负责"做出来"，检查工具负责"验一遍"。**生成的封装不需要人工先过目，可以直接丢给检查工具验收。**

## 二、工具效果

### 2.1 案例器件

**3S48000163 无源晶振**（SMD，本体 3.2 × 2.5 mm，4 个焊盘）——库里有人工做的标准件可以逐值对照。

### 2.2 生成文件

一个归档文件夹，里面封装三件套 + 规格书 + 校验记录：

```
<规格书所在目录>\NB_XTAL4_3D2X2D5X0D7\
├── NB_XTAL4_3D2X2D5X0D7.dra     ← 封装图纸（可编辑）
├── nb_xtal4_3d2x2d5x0d7.psm     ← 成品（画板子时真正调用的）
├── r1d4x1d2.pad                 ← 焊盘定义
├── <规格书>.pdf                 ← 同型号规格书，跟封装放在一起
└── README.md                    ← 清单 + 校验值 + 尺寸出处
```
### 2.3 质量检查结论

生成的封装可以直接交给检查工具（19 项自动检查）验收。

说明：目前生成和检查是**两个工具分开跑**，还没有自动串成一条流水线。

| 对拍项                                 | 结果                                            |
| ----------------------------------- | --------------------------------------------- |
| 几何参数逐值对拍（焊盘尺寸 / 坐标 / 本体 / 占位框 / 位号） | **164 / 164 全部对上**                            |
| Allegro 内建模步骤                       | **35 步全部成功**，0 步失败                            |
| 编译出成品 `.psm`                        | **连续 3 次成功**，每次 0.6\~0.7 秒，全程零人工点击，产物 8644 字节 |

## 三、操作方法

> **部署方式**：当前处于**本地测试阶段**，服务装在使用者自己的电脑上；
> 后续会安排服务器部署，改为远程调用服务——**使用方式不变**。

### 3.1 部署

自动化封装工具目前**没有做迁移化重构**，重构后效果如下：

| 项目      | 重构后（照检查工具的流程）                                     |
| ------- | ------------------------------------------------- |
| 装服务     | 一条命令：`curl -L -o deploy.bat <脚本地址> && deploy.bat` |
| 装依赖     | 脚本自动装（缺 uv / git 会自己下载）                           |
| MCP 配置  | 脚本自动生成并打印，直接粘                                     |
| SKILL配置 | 技能随项目走，脚本直接给出路径                                   |
| 日常使用    | **通过AI对话**                                        |
### 3.2 创建封装

**实现**：在对话框里输入（给规格书路径，或给装着规格书的文件夹）：

```
帮我根据这份规格书建立封装：<规格书路径>
```

**成功**：AI 自动跑完整个链路，回报"成功"，并列出产出的文件和归档位置。

**AI自动化操作（不用人工去管，但报告里能看到）**：

| 阶段     | 干什么                                                |
| ------ | -------------------------------------------------- |
| ① 找尺寸页 | 在规格书里定位"推荐焊盘图"那一页，渲染出来读参数                          |
| ② 离线对拍 | 先算出几何并打印对拍表，**每个数都要在规格书上有出处**                      |
| ③ 建模   | 驱动 Allegro 建焊盘 → 放引脚 → 画丝印 → 画本体 → 画占位框 → 写位号 → 存盘 |
| ④ 编译   | 编译出 `.psm` 成品                                      |
| ⑤ 验证   | 编译日志 + 规则检查 + 回读复核，三重都对才算完                         |
| ⑥ 归档   | 三件套 + 规格书放进**与封装同名的文件夹**                           |

>  任何一步失败会**立即停下**并给出中文原因（如"缺位号"、"引脚编号重复"），不会硬着头皮画出一个半成品。

### 3.3 取出封装

**实现**：到归档目录（**规格书所在目录下、与封装同名的文件夹**）取三件套。

**成功**：目录里 `.dra` + `.psm` + `.pad` 三样齐全，且 `.pad` 与 `.dra` 在同一目录。
