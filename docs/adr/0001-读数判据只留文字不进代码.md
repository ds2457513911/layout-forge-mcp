# ADR-0001 读数判据只留文字，不进代码

`allegro-footprint-check` 的读数判据（整页图只定位、区域裁剪 ≥600 dpi、交叉校验 ≥2 条且不同源）以文字规则写在 SKILL 第 3 步，不落成 forge 侧的自动判定代码。

- **Status**：Accepted（2026-11-19）
- **背景**：2026 年建过一条「读图判据」管道，试图用代码判定一次读数是否合规；管道已废弃。判定要「看懂图纸」，属 Agent 层语义判断（`docs/SOP-工程维护手册.md` §1.1 的语义 / 数值分工）。今天 `eval/` 里没有读数规则断言，是这条取舍的结果，不是遗漏。
- **被否方案**：重建 judge 管道 —— 输入是模型读出的数，代码无法复核它读得对不对，只会把「合规」变成「格式正确」；把规则写进 `eval/suites/architecture/check_architecture.py` —— 那里只查文件结构与导入方向，不查文档措辞。
- **代价**：违反读数规则不会被自检挡住，只能靠评审与引用本条 ADR；SKILL 第 3 步的措辞改动需要人审。
- **何时重估**：读数工具能输出「这个数出自哪块图」的结构化证据时，判据可下沉为字段校验，本条作废。
