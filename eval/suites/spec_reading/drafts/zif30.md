### `body_y` 的口径差异（已记录，未擅自改动任一侧）
- `.dra` 符号名写 `4d3` → 4.30，与图纸标 `4.30` 名义值同源，**agree 成立**。
- 但 `.dra` 几何里 y 向存在**更深的轮廓**：`assembly_top` bbox 深 **5.854**、全部焊盘 y 跨度 **5.600**。即"装配/焊接区"在 y 向比 4.30 本体宽更深（含翻盖/插入口机构）。
- 判断：canonical `body_y` 取图纸明确标注的 **4.30**（本体宽），5.854/5.600 属装配区与焊盘区跨度，非"器件本体宽"。**两个值都留在此处**，供人工裁定。

## 四、不确定项与理由

1. **焊盘轮廓像素实测 vs 标注（次要，已按标注+`.dra` 双证定值）**
   PCB 焊盘视图按图形轮廓逐像素扫描，单个焊盘外框实测约 **0.52 × 1.52 mm**，而图注为 `0.30` / `1.30`。差异可解释：`0.52` ≈ 0.30 + 0.2×... 实为 **0.30 + 单边 soldermask 外扩 0.10**（`.dra` 同款外扩仅 0.05 → 0.4，量级同阶）；`1.52` 与 `1.30` 差 0.22，落在同一量级的轮廓/抗锯齿误差内。
   本草案**以图注 `0.30` / `1.30` 与 `.dra` 实测 `0.3 × 1.3` 双重证据为准**，未采用像素扫描值。置信度：`high`（双证一致）。

2. **`DIM C = 15.57` 与图纸实测引脚跨度 14.50 不符（未影响 canonical 字段）**
   表列 `DIM C(30) = 15.57`（= DIM A + 1.07），但顶视图/PCB 视图实测 30 个引脚中心跨度为 **14.50**。表内 DIM A/B 与图纸实测吻合，仅 DIM C 对不上。因 `body_x` 由 `DIM A + 2×(2.25)` 得出、已获 `.dra` 19.0 独立确证，**该不一致不改变任何 canonical 值**，仅记录备查。

3. **第 2 页为卷带包装图**
   `NOTES 1–8`、载带/卷盘尺寸（`φ330`、`φ80`、`13"`、`2000PCS`、`PULL OUT DIRECTION`、`PEEL OFF DIRECTION`、`SECTION A-A`/`DETAIL B` 的载带腔尺寸）——**无 land pattern 尺寸**。故 `page` 全部为 1。

4. **`pad_x`/`pad_y` 语义歧义（已按 FPC 惯例 + `.dra` 同向定值）**
   canonical 的 `pad_x/pad_y` 是"宽/高"还是"长/宽"未在题面明确。本草案取 **`pad_x` = 沿引脚排列/插入方向的长边（1.30）、`pad_y` = 跨 pitch 方向的宽（0.30）**，依据：(a) 两处标注 `0.30±0.03` 与 `0.50` 间距相邻取宽、`1.30` 单独跨焊盘长边；(b) `.dra` 信号焊盘 `x=0.3, y=1.3`，与引脚排列方向（x）正交的正是 1.3。若人工裁定为另一种口径，`pad_x`/`pad_y` 应互换（`1.30 ↔ 0.30`）。

5. **无既有 spec 可对照**
   本案例为新增例，仓库内无 `zif30` 历史 spec；亦**未**套用同族 `fpc0510_6p` 的参数（题面点名此为易错点）。参考：`.dra` 为人工封装，独立口径，仅用于交叉核对。
