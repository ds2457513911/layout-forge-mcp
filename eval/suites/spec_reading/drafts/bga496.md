## 2. 页码选择依据：为什么主引第 12 页

规格书只有两张 Package Dimensions 图，且**8 个 canonical 字段在两页取值完全相同**：

| | 第 11 页 Figure 5 | 第 12 页 Figure 6 |
|--|--|--|
| 封装代号 | Package Code **BG** | Package Code **CH** |
| 对应料号（p2 Table 1） | `MT62F512M64D4BG-031 WT:B`（4 die / 4GB） | `MT62F1G64D8CH-031 WT:B`（**8 die** / 8GB） |
| 球高尺寸串 | `0.58 ±0.09` | `0.68 ±0.09` |
| 对应 p1 seated height | 0.67mm (MAX) | 0.77mm (MAX) |
| 10.8 CTR / 0.4 TYP / 10.4 CTR / 0.4 TYP | 相同 | 相同 |
| 14 ±0.1 / 12.4 ±0.1 / 496X Ø0.27 ±0.05 / Ø0.24 SMD ball pads | 相同 | 相同 |

本案例名含 `8dp`（8 die in package，p1 的 `D8 = 512M16 × 8 die in package`），据第 2 页 Table 1，8-die 料号对应 **Package Code CH → Figure 6 → 第 12 页**，故**主引第 12 页**。第 11 页可作等价佐证，差异只在球高（不属 8 字段）。
另：修订历史（第 18 页）Rev. C 条目 "Updated legal status to Production for **MT62F1G64D8CH**" 也印证本案例对应 CH 封装。
