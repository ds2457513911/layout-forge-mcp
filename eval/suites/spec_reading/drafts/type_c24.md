## 2. 读数是怎么来的（可复现）

### 2.1 为什么走矢量几何而不是 OCR / 目视标尺
`ps.probe_pdf()` 报 `drawings: 0`，但这是 **probe 的误报**（对 `printed` 形态提前短路）：实测 `page.get_drawings()` 在 P1 = 3833 条、**P2 = 1673 条**。整本 PDF 的图形本体是矢量，42 张位图全是 `bbjconn` logo。因此测量精度不受渲染 dpi 限制，dpi 只用于**目视核对**。

### 2.2 标定比例 27.178 pt/mm（三重独立自洽）
| 佐证 | 矢量实测 | 图上标注 | 反推 pt/mm |
|--|--|--|--|
| 同排相邻焊盘中心距 | 13.589 pt | `0.50` | 27.178 |
| 焊盘宽度（左右边差） | 7.338 pt | `24X0.27±0.05` | 27.178 |
| 一排骨 12 枚总跨距（11 间距） | 149.486 pt | `5.50` | 27.179 |
| B 排焊盘高 | 21.743 pt | `12X0.80±0.05` | 27.179 |

### 2.3 焊盘阵列实测（P2，PDF pt 坐标）
| 项 | A 排（A1..A12） | B 排（B12..B1） |
|--|--|--|
| 焊盘顶/底 y | 192.671 / 217.132 | 237.517 / 259.260 |
| 焊盘高 | 24.461 pt = **0.900 mm** | 21.743 pt = **0.800 mm** |
| 焊盘宽 | 7.338 pt = 0.270 mm | 7.338 pt = 0.270 mm |
| 左边缘 x | 213.433 + 13.589k | 206.639 + 13.589k |
| 行心 y | 204.902 | 248.389 |

- 两排 **x 向错位 6.794 pt = 0.25 mm**（半间距交错）；两排 **行心距 43.487 pt = 1.600 mm**。
- 焊盘整体 x 跨度 206.639 → 370.257 = 163.618 pt = **6.020 mm**（与 P2 的 `7.20±0.03` / `7.80 min` 同量级，属外壳范围内）。

### 3.1 唯一的分歧：`pad_y` 单值
两侧**本身都不冲突**，冲突发生在「只取一个值」的口径上：

- PDF 侧：图上唯一成文的高向标注是 `12X0.80±0.05` ⇒ 取 **0.80**；但 A 排 0.90 是矢量实测（24.461 pt）得到，非猜测。
- `.dra` 侧：几何里**同时**存在 0.8999（A 排）与 0.8001（B 排）；项目自己的 benchmark 取首枚 pin 会落到 A 排 ⇒ **0.90**。
- 双向自洽证据：PDF 的 A/B 高比 24.461 / 21.743 = **1.125**，`.dra` 的 0.9 / 0.8 = **1.125**，完全吻合 ⇒ 两排高矮在两侧都被证实是 0.90 / 0.80。
- **处置**：不改读数、两值并列。草案取成文值 **0.80**，把 `0.90` 留在 `cross_check.disagree` 与 notes，请人工签字时定口径（若评审方口径为「取最大/首排焊盘」则应写 0.90）。

### 3.2 非分歧但需要说明的差异
- `.dra` `place_bound_top` = 10.58×10.29（含避让/卡口），比本体 8.94×9.17 大。canonical 的 body 取**本体轮廓**（`assembly_top`），与 PDF 的 `(8.94)/(9.17)` 同源；同项目既有 `lydpj_5p_12x6` 也是取 assembly/silkscreen 轮廓而非 place_bound。

- 8 枚机械脚明细（不计入 pin_count，仅存档）：pin1/3 `POB1D9X0D6HO2D3X1D2` @(∓4.32,0.05) 1.1999×2.3 / 槽 0.5999×1.8999；pin2/4 `POB1D25X0D7HOB1D65X1D1OSY0D1` @(∓4.095,−0.5499) 1.65×1.1001 / 槽 1.2499×0.7；pin5/6 `POB2X0D7HOB2D6X1D3` @(∓4.32,−5.0) 1.3×2.5999 / 槽 0.7×2.0；pin7 `NPC0D6` @(−3.5999,−1.95) 圆孔 Ø0.5999；pin8 `NPOB0D85X0D5` @(3.5999,−1.8849) 槽 0.8499×0.5001。

## 4. 不确定项与理由（请人工裁定）

### 4.1 ★ 最大项：`body_x` / `body_y` 的**轴归属**
PDF 只给出两个数：`(8.94)` 与 `(9.17)`，两者同在第 1 页。哪个记 `body_x` 属**口径裁定**，不是图上读数：

- **读法 A（本草案采用）**：`body_x = 8.94`、`body_y = 9.17`。
  - 依据 1：canonical 口径下 `body_x` 与 `pad_x`/`pitch_x` **同轴**（都是封装 X 向）。代码层证据：`Tools/benchmark_golden.py:92-105 _body_from_place_bound()` 用 place_bound bbox 的 **X 向宽度**填 `body_x`、Y 向高度填 `body_y`，而 `services/spec_library.py:106-135 fingerprint()` 又把它与 `knowledge/specs/*.json` 的 `spec.body.x / body.y` 直接比对 —— 两者必须同轴，否则指纹匹配必然失败。
  - 依据 2（**PDF 内部即可判**）：P1 的 `(8.94)` 所量的方向正是 12 枚焊盘成排的方向（焊盘沿本体宽度方向排列），而 P2 推荐 land pattern 的横轴（图内 `-X-` 基准）就是焊盘阵列方向 ⇒ **8.94 属 X 轴**。
  - 依据 3：`.dra` 本体轮廓 X=8.9401 / Y=9.1701，与读法 A 完全一致。
- **读法 B（README 字面「本体长 / 本体宽」）**：`body_x = 9.17`（长）、`body_y = 8.94`（宽）。
  - 支持它的东西只有 `.dra` 文件名 `nb_type_c24_9d17x8d94x3d31` 的数字顺序（9.17 在前）。
  - **但项目明确不认文件名顺序**：同项目既有件 `b_audio6_12x7d25x4d3.dra` 对应的候选 `candidates/audio6_cstj421.json` 是 `body_x=7.59 < body_y=12.2` —— 名字先写 12，体值 `body_x` 却是**短边** 7.59。另有 `drafts/lydpj_5p_12x6.json` 明写 `.dra` 名 `nb_audio5_13d05x6d3x4d2` 的三个数「与实测对不齐，疑为历史命名遗留」；`drafts/tf9.json` 的 `.dra` 名 `nb_tf9_14d5x16d19x2` 也把 16.19 写在第二个而 `body_x=16.19`。
- **处置**：两读法的数值都在两侧留下，未做掩盖。签字时若改口径，**只需改这一处**（8.94 ↔ 9.17 对调）。

### 4.2 ★ 次项：`mount` = `smd` vs `tht`
本件是**混合装配**：24 枚 SMT 端子 + 4 枚「板上四脚插」外壳脚（THT）+ 4 枚定位柱。

- 取 `smd` 的理由：canonical 的 8 个字段整体按**信号脚**口径（README 明确 `pin_count` 不计外壳脚/定位柱）；`pad_x/pad_y` = 0.27×0.80 正是信号脚的 SMT 焊盘，若 `mount=tht` 则与「200 多微米的裸 SMT 焊盘无钻孔」自相矛盾。项目实现同此口径：`services/geometry_solver.py:457-487` 用 `mount` 决定**主（信号）padstack** 是否加 drill、是否刷锡膏 —— 本件信号 pad 是 `ETCH/TOP` + `SOLDERMASK_TOP` + `PASTEMASK_TOP` 三件套、无 DRILL，故主 padstack 必须是 SMT；`services/convention_engine.py:277-287` 也只在 `mount == "tht"` 时改主 padstack。
- 若评审方口径是「整件是否需要通孔/是否需要插件工艺」，则应记 `tht`（件名里的「板上四脚插」即指此）。
- 置信度：**medium-high**（功能一致性站在 smd 一侧，但本件客观上是混合件）。

### 4.3 其它
- **`pitch_y` 图上无标注**，纯矢量实测 1.600（`.dra` 独立复现）。两排在 x 向错位 0.25，故最近一对 A-B 引脚的行心距是 1.600、斜距 √(0.25²+1.60²)=1.619，两种算法都在 ±0.02 内独立成立，不构成分歧。
- **`pitch_x` / `pitch_y` 的轴向**已在草案 note 与 candidates `method` 中写明口径（x = 焊盘阵列方向、y = 垂直方向；THT/外壳脚距不计入间距）。
- **规格书自身的缺省**（非读数失败）：A 排焊盘高 **0.90 在 P2 上没有任何成文尺寸标注**，只能靠矢量实测 + `.dra` 双证。P2 上的 `(0.90)` 是左侧外壳/柱特征的参考尺寸（bbox x≈69–79pt，离焊盘阵列 x≥206pt 很远），不是焊盘高。

- **规格书页数与 probe**：`probe_pdf` 的 `drawings: 0` 是误报（见 2.1）；`locate_land_pattern_page` 用 fallback 命中 P2，未失配。
