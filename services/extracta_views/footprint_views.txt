# ============================================================
# extracta 视图定义：一个 .dra → pins + pads + geometry + ref_des
# ============================================================
# 四个视图对应四个输出文件，命令行按顺序对应：
#   extracta <dra> footprint_views.txt pins.txt pads.txt geom.txt refdes.txt
#
# 重要：PAD_DEF 视图不接受字段声明（见 pad_rep.txt 的注释），
#       只写视图名 + END，它会自动输出固定列（PAD_NAME / REC_NUMBER /
#       LAYER / ... / APADSHAPENAME）
#
# ★ 为什么要单独一个 REF DES 视图（2026-09-29 实测）：
#   FULL_GEOMETRY 的 `CLASS = "..."` 是**过滤器**，不是"顺带多读一层"。
#   视图 3 只取 PACKAGE GEOMETRY，所以位号（CLASS = REF DES）读不到 ——
#   表现为 texts 里只有 PIN_NUMBER、没有 #REF，而且**不报错**（静默缺口）。
#   实测把过滤条件换成 CLASS = "REF DES" 立刻读出
#   `REF DES/ASSEMBLY_TOP = "#REF" @ (-0.15, 0.04)`，所以是**视图没配**，
#   不是 extracta 没这个能力。
#   实测 extracta 支持 4 路输出（每条 FULL_GEOMETRY 视图对应一个文件），
#   所以几何视图保持原样不动，位号另开一路，互不污染。
# ============================================================
